          Overview
An interactive rating component where users can:
  -Select a rating from 1 to 5
  -Submit their feedback
  -See a thank-you state after submission
  -Interact with hover and focus states
The project is fully responsive and works correctly on mobile, tablet, and desktop devices.  

            Built With
--HTML5
--CSS3 / SCSS
--JavaScript
--Flexbox

            Features
---Interactive rating buttons
---Dynamic thank-you state
---Hover and focus effects
---Responsive design
